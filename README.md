Hostel Takeover is an original one-shot adventure for 3 to 6 Alpha-clearance characters written by Torg Eternity designer Darrell Hayhurst. This adventure was originally published in the 2018 book Delphi Missions: Rising Storm and has been fully adapted for Foundry VTT.

This free module includes the following features:

Six Threats, complete with portraits, tokens, and appropriate gear and special abilities to challenge your players.
Two maps from the original adventure, which have been enhanced to include dynamic lighting and line of sight and are ready for play.
The complete text of the adventure to guide you through Hostel Takeover from start to finish.

There are two installation options:
- Create a new world, and choose the Hotel Takeover adventure to auto-populate the world.
- Enable the module in a world, then import the adventure from the supplied compendium module.
